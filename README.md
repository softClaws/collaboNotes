# Collabo Note

Collabo Note, this is a note management web app that helps to users to effectively and dynamically keep notes. This attempt to encourage writing culture and allow Creator and Contributor to explore there 

## 🚀 Demo

[Live Demo](https://#)


## 🧰 Features

- Create, Edit, Delete, assign Roles( Creator, Contributor) to Note!

## 📦 Tech Stack

- Frontend: React, HTML, CSS, React Router, Redux
- Backend - NodeJs,ExpressJs, MongoDB

## ⚙️ Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/softClaws/collaboNotes.git
cd backend
npm install
cd ..
cd collabo_note
npm install
npm run dev
